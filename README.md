# מפות ישראל אופליין – Android

פרויקט Android עצמאי עבור מפות ישראל ללא חיבור לאינטרנט.

## עקרונות
- ממשק בעברית ובכיווניות RTL.
- הצגת מפה וקטורית מקומית באמצעות Mapsforge.
- נתוני המפה נשמרים בנפרד מה-APK כדי למנוע ניפוח של קובץ ההתקנה.
- אין תלות בשירותי מפות מקוונים בזמן הצגת מפה מקומית.

## מצב הפיתוח
זהו שלד Android ראשון שמכין את סביבת האפליקציה ואת מנוע הצגת המפה המקומית. הוא אינו כולל עדיין את קובץ המפה של ישראל, חיפוש מקומי או מנוע ניווט. אין להציג את הגרסה הזו כאפליקציית ניווט מלאה עד להשלמת בניית הנתונים ובדיקות אופליין.

## מבנה נתונים מתוכנן
- `files/maps/israel.map` – מפה וקטורית מקומית.
- מסד SQLite נפרד לחיפוש בעברית.
- גרף ניתוב מקומי למסלולי רכב, הליכה ואופניים.
- חבילת נתונים נפרדת, דחוסה וחתומה עם בדיקת SHA-256.

## Build
GitHub Actions builds a debug APK on push or manual dispatch. The APK is a development build, not a signed release.
